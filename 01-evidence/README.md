# 01-evidence — 原始资料与可追溯证据

**状态：2026-10-09 公开证据洞察研究已经有边界结题。** 此目录是规范化原始研究证据存储，不是“Wave 0 空仓”。文献数量以规范化 Source 身份为准，不能把 `README.md` 与 `deep.md` 文件数当作独立论文数。

## 分类与具体入口

- [papers/](papers/)：学术论文及其原始来源、技术机制、发表信息、论文十问和适用边界。
- [patents/](patents/)：专利与权利要求核对；申请、授权、产品部署和法律自由实施(FTO)不可混同。
- [vendors/](vendors/)：官方厂商、OS/SDK、产品与技术文档；官方声明不等于独立系统实测。
- [tools/](tools/)：LLVM/MLIR/AArch64/KleidiAI 等工具或开源实现；代码存在不等于特定手机环境测得收益。
- [discovery-runs/](discovery-runs/)：文献发现/扩展与检索历史，用于溯源，不覆盖源事实。

来源卡片间的证据独立性、原始网页直读/受限程度和当前结论精确边界以[Round15G决策关键来源审计](../analysis/audits/round15g-final-source-and-ssot-audit-2026-10-08.md)为准。审计不是世界文献穷尽检索或所有URL的实时有效性承诺。

研究结题及是否需未来定向补证，请读[正式结题验收](../00-project/final-research-archive-acceptance-2026-10-09.md)；现行研判请读[09-roadmap/current.md](../09-roadmap/current.md)。历史阶段的证据卡继续保留，不能因已结题批量删除。
