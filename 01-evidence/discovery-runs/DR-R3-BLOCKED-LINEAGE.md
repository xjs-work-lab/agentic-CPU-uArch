# DR-R3-BLOCKED-LINEAGE

## Purpose
Preserve why R3 is **BLOCKED**, not merely low-scored.

## Frozen deployment-depth chain
- **D0:** Agent/compiler/workflow → Agent-aware runtime.
- **D1:** runtime → FFRT / Gewu / OS / kernel via derived generic control facts.
- **D2:** system/runtime → CPU/hardware hint or low-level policy.

## Frozen gate logic
D2 does not activate because:
1. D0 has not yet reached target-phone SYSTEM_VALUE;
2. D1 incremental value beyond strong D0 translation remains conditional and software-sufficiency-gated;
3. Stage15 D1 sensitivity shows the residual collapses rapidly as software capture rises;
4. R1 and R2 hardware-specific parents remain measurement-only;
5. no stable lower-layer consumer with SYSTEM_VALUE exists.

## Hardware gate
A D2/uArch path requires:
`SYSTEM_VALUE → SOFTWARE_INSUFFICIENCY → hardware-specific cause → UARCH_CANDIDATE`

Direct decision-critical prior-art review and product/economics gates remain additional prerequisites.

## Boundary
This is decision-lineage preservation only.
No dedicated R3 hardware program is created by migration.
