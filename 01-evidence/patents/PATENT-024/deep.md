# PATENT-024 — Cache-Demand-Aware Heterogeneous Scheduling — direct-claim audit

## Source
- US9626295B2
- Primary: https://patents.google.com/patent/US9626295B2/en
- Assignee lineage: Qualcomm
- Priority: 2015-07-23

## Direct-claim result
Claim 1 directly recites:
- two heterogeneous processor clusters;
- different performance/shared-cache characteristics;
- running a task on one cluster;
- monitoring processor workload and task cache demand;
- calculating a weighted combination and comparing to a threshold;
- migrating the task to the second cluster when the decision condition is met.

Dependent claims use cache-miss counters and per-task cache-miss information.
Claim 23 explicitly includes smart phone and tablet device categories.

## Project decision
This is a direct mobile/portable claim-level anchor for generic cache-demand-aware heterogeneous scheduling/migration.

It strongly constrains broad R2 novelty but does not establish:
- Agent future-state semantic information;
- target-phone Agent-specific microstate residual;
- benefit from a new Agent-aware hardware structure.

No FTO/legal conclusion.
