# PAPER-038 — Beyond the GUI Paradigm

## 30-second read
- Strong benchmark evidence that GUI-only is not a universal mobile action surface: ADB/CLI can reach bulk, aggregate, cross-app and hidden-state operations with fewer interaction steps.
- Oracle CLI solves 103/116 AndroidWorld and 101/117 MobileWorld tasks; the rest includes genuinely visual/capture/panel-only tasks.
- Critical boundary: experiments use ADB plus benchmark-level structured/backend access in emulator/container environments. This is **not proof that a retail phone Agent has those privileges**.
- Primary source: https://arxiv.org/abs/2606.19388
