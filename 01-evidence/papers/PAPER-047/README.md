# PAPER-047 — Decoupling Readiness from Release

- Direct Agent-system evidence that readiness and release can already be decoupled in software.
- V1 records release-order / released-work-budget control using workflow tail risk, online work estimates and queue pressure, with up to **3.50x P95 workflow flow-time speedup** under contention.
- **Boundary:** server/workflow tail latency, not smartphone energy/QoE or CPU post-ready µs–ms timing.
- **Decision use:** broad ready/release decoupling is not differentiated R1 novelty.
