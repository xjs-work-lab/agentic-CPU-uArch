# DEC-H-CAL-002 — Close Contiguous Agent Learning as a standalone second-Bet candidate

## Previous state
H-CAL — narrow analysis hypothesis awaiting direct mobile residual pressure.

## New state
**H-CAL — KILLED AS STANDALONE DIRECTION / SECOND-BET CANDIDATE.**

Contiguous Agent learning remains an important workload and evaluation scenario.

## Why
The reviewed evidence leaves no distinct H-CAL-owned smartphone CPU/system control variable:
- generic training layout, memory and energy are strongly software-capturable;
- adapter lifecycle is explicitly represented in software;
- LoRA identity and mobile app lifecycle are already usable KV-cache signals;
- adapter-version/KV validity is handled by LOCAL runtime and maps naturally to B-residual coherence;
- foreground/background admission and thermal policy map to C;
- cache locality/residency maps to R2 / CG-01 when direct phone residual exists;
- training dependency itself can be altered algorithmically.

The remaining public-evidence gap is direct phone measurement of live Agent serving plus repeated local adaptation. That gap is a reason not to promote, not evidence for a new lane.

## Merge map
- update timing / foreground protection / thermal budget → C workload scenario;
- adapter publication / stale KV correctness → B-residual;
- cache retention/locality → R2 / CG-01 only with direct residual;
- backward kernels/layout/training runtime → generic platform/compiler optimization;
- personalization/continual-learning demand → workload/radar dimension.

## Reopen condition
Reopen only if direct target-phone evidence shows a material residual after LOCAL + MobiLoRA + strongest mobile-training/scheduling baselines that cannot be represented by C/B/R2 software and exposes a reusable new control point.

## Portfolio impact
No new Direction. No score changes. Second differentiated Primary Bet remains unfilled. No uArch candidate.
