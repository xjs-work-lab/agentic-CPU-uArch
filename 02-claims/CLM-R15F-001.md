# CLM-R15F-001

## Proposition
Mobile CPU SME2 can have practical inference benefits using existing ISA and kernels; official Arm/PyTorch vivo X300 SqueezeSAM reports single-core INT8 latency about 556 to 304 ms and FP16 1163 to 298 ms, with around 40% of accelerated time from data movement.

## Scope and uncertainty
Official author-involved device report of vision segmentation; not an Agent workflow or optimized NPU comparison.
