# CLM-AO3-006

## Proposition
After strong software and prior-art pressure, a credible open architecture opportunity remains in the cross-engine lifecycle of persistent Agent state: preserving useful state across CPU/NPU/GPU handoffs, matching state lifetime to scarce on-chip/shared memory, propagating version/validity changes, and avoiding repeated serialization/rebuild when the same logical Agent resumes.

## Boundary
Public evidence shows the ingredients separately but does not yet demonstrate that a unified hardware state fabric is necessary or optimal.
