# CLM-AO4-001

## Proposition
Smartphone proactive assistants require repeated contextual observations and an explicit intervention/no-intervention decision before candidate actions; this can create a persistent low-duty front-end workload.

## Boundary
PAPER-087 defines a benchmark task and context dimensions, but does not measure production sampling rate, continuous sensor budget or phone battery impact.
