# CLM-R15C-002 — SUPPORTED

## Proposition
Android NN HAL burst execution already provides same-model resource persistence, memory mapping reuse and FMQ low-overhead dispatch; Qualcomm QNN HTP offers shared CPU/DSP buffers and external-context memory handles with mode and concurrency restrictions. Generic zero-copy/shared-buffer and persistent execution context cannot alone distinguish Agent-era hardware.

## Boundary
NNAPI NDK deprecated Android 15; historical HAL designs do not establish current API adoption. Qualcomm SDK subsection material was extracted from indexed official docs, not a full SDK scan. Neither source proves arbitrary cross-model/version zero-copy or phone-Agent benefit.
