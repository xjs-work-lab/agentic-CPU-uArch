# CLM-AO2-006

## Proposition
After strong software and prior-art pressure, a credible but unproven architecture opportunity remains only if speculative/revised Agent work materially occupies local CPU/NPU/GPU queues, KV or intermediate state such that cancellation, invalidation, selective inheritance and resource reclamation become expensive below the runtime boundary.

## Boundary
Public evidence establishes the semantic pattern, but does not establish that this lower-layer cost is material on smartphones.
