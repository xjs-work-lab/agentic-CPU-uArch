# CLM-AO1-004

## Proposition
Major mobile compute vendors now publicly position Agentic workloads as a system/subsystem architecture problem involving CPU orchestration, heterogeneous compute, shared/coherent memory or cache and larger/specialized accelerator-local state rather than only faster standalone NPU inference.

## Boundary
This is public vendor architecture/product positioning. It does not independently validate quantitative performance claims or prove that the same architecture is optimal for our target.
