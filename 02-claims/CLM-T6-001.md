# CLM-T6-001

## Proposition
In SkillDroid's controlled Android-emulator evaluation, compiling successful LLM-guided GUI trajectories into persistent parameterized UI-action skills materially improves repeated-task success and reduces LLM-call demand versus the same TaskOrchestrator stack without skill matching/replay/compilation; pure replay can execute without an LLM call.

## Current interpretation
This is direct evidence that repeated mobile-Agent behavior can become a reusable **executable procedural artifact**, strengthening T6's product relevance.

## Boundary
The experiment runs on a Windows 11 host driving a Pixel 9a/API 35 emulator via ADB. It is not a physical-phone CPU/energy/thermal result.
