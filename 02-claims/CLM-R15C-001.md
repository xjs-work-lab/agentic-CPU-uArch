# CLM-R15C-001 — SUPPORTED

## Proposition
Android 17 NPU Manager publicly specifies system-level model-load admission, priority coordination, unload/cancel requests, and driver-reported work start/resume/pause/end/cancel states through an NPU Scheduling HAL. Broad OS-aware NPU scheduling and work lifecycle signaling are thus already platform API mechanisms, not differentiated Agent-only CPU-uArch novelty.

## Boundary
Public documentation specifies capabilities and vendor integration; it does not prove commercial deployment on every Android 17 smartphone, dedicated Agent goal semantics, CPU/GPU/NPU coherence or a measured task-QoE result.
