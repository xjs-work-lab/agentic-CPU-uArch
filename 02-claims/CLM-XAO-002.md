# CLM-XAO-002

## Proposition
AO-4 decides which observed events deserve waking richer Agent computation while AO-5 governs the value and legality of work that progresses; both may feed AO-1's cross-engine execution decisions but the two admission/control decisions are not identical, and strong learned/software gates must be admitted before hardware proposals.

## Boundary
This is a conceptual layered co-design model; no reviewed single mobile device implements all three layers as one stack or measures energy+task-success advantage.
