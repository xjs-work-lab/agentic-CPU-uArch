# CLM-AO4-003

## Proposition
A plausible proactive stack performs cheap trusted event/context filtering first, then lightweight multimodal intervention gating and function candidate narrowing, and invokes expensive Agent reasoning or actions only for accepted opportunities.

## Boundary
This is a cross-source architecture synthesis: CHRE, Apple wake-word hierarchy and PRPF solve different scope levels; no source implements this exact stack on one production phone.
