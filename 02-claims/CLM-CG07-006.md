# CLM-CG07-006

## Proposition
Proactive mobile Agent workloads can require an explicit **intervention / no-intervention** decision over ongoing user, device, world and behavioral context before executable assistance is generated.

## Current interpretation
PAPER-087 makes selective intervention a first-class mobile Agent workload property rather than assuming every context observation deserves expensive reasoning.

## Boundary
This is workload/capability evidence. It does not establish real production context-arrival rate, intervention duty cycle, phone energy cost or the need for a dedicated hardware domain.
