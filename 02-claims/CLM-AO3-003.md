# CLM-AO3-003

## Proposition
Validated replay, chunk compression, swap/recompute overlap, learned reuse prediction, version/provenance checks and dependency-scoped invalidation already capture substantial persistent-state value in software, so generic Agent memory, KV caching or semantic invalidation are not sufficient reasons for new hardware.

## Boundary
The software baseline is strong but fragmented across state classes, engines and tiers; it does not prove that all cross-engine mobile state handoff cost is eliminated.
