# CLM-AGENT-009

## Proposition
Long-horizon multimodal Agents can benefit materially from a continuously built and updated external memory lifecycle that includes episodic memory, semantic consolidation, structured entity/relationship state, and task-time retrieval beyond a one-shot model context.

## Evidence
PAPER-071 / M3-Agent (ICLR 2026).

## Boundary
This establishes **Agent capability value**, not smartphone-system cost.

It does not establish:
- a vector database as the only representation;
- on-device feasibility;
- a specific query/update rate;
- CPU/NPU/DRAM bottlenecks;
- hardware/uArch necessity.
