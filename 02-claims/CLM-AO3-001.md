# CLM-AO3-001

## Proposition
Mobile and local Agent systems increasingly accumulate long-lived reusable state beyond transient model activations, including KV/context, profile memory, procedural experience, validated action traces and adapter/version state; reusing that state can materially reduce repeated inference and context-switch cost.

## Boundary
Different sources cover different state classes. This claim does not imply that all state should share one physical memory mechanism.
