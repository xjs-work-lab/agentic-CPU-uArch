# CLM-AO1-001

## Proposition
Personal-Agent execution can form concurrent long-lived reactive-foreground plus proactive-background flows whose latency/throughput priorities and prefill/decode phase behavior differ enough that isolated single-shot inference assumptions become a poor system model.

## Boundary
Direct system evidence is from an Intel consumer heterogeneous SoC, not a smartphone. The result establishes a new execution regime, not a requirement for new silicon.
