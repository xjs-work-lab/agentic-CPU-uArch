# CLM-AO1-003

## Proposition
Flow-aware scheduling, admission control, affinity, preemption, accelerator coordination and state/KV retention can recover substantial Agent-system value on commodity hardware, so heterogeneous Agent execution by itself is not evidence for new CPU/SoC hardware.

## Boundary
The evaluated systems expose enough runtime state for these controls. This does not prove that every mobile cross-xPU control/state cost is software-reconstructible or cheap.
