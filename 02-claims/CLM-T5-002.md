# CLM-T5-002

## Proposition
When a local Agent updates LoRA adapters while continuing to serve inference, KV reuse must account for adapter version and state lifecycle; software-managed version-aware validity, staged hot-prefix refresh and memory-aware residency can materially reduce post-update latency while preserving correctness on the evaluated single-GPU runtime.

## Current interpretation
PAPER-104 makes adapter version, KV validity, refresh and residency a concrete strongest software baseline for T5.

## Boundary
The result is on an RTX 3090-class 24 GB GPU with 7B-class models, not a smartphone SoC. Phone energy, thermal and foreground-app QoE are unmeasured.
