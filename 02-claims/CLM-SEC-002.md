# CLM-SEC-002

## Proposition
Dynamic Agent app/tool collaboration, permission relationships, trusted-vs-untrusted control/data flow, value provenance and cross-Agent capability propagation are already representable and enforceable as explicit runtime/software state; these facts alone do not establish a new lower-layer trust-graph primitive.

## Evidence basis
- PAPER-084 / IsolateGPT — hub/spoke app isolation, structured collaboration, explicit permissions;
- PAPER-085 / CaMeL — trusted control flow, quarantined data, dependency graph, capabilities and tool-call policy;
- PAPER-086 / multi-CaMeL — instruction/data channel separation plus provenance/capability preservation across Agent-as-tool boundaries.

## Boundary
Software capture does not prove that its smartphone cost is negligible.
A lower-level opportunity could reopen only if direct mobile evidence shows software enforcement is materially too costly or insufficient.
