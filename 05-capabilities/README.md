从[Source](../01-evidence/README.md)到[Claim](../02-claims/README.md)、[Evidence Case](../03-evidence-cases/README.md)形成证据链；只有[正式决策组合](../09-roadmap/current.md)具有当前方向权威。早期 Wave 0 空仓描述已经不适用。
