## 每轮固定输出（简洁，但不省略）

### 1. 最终项目目标
以公开论文、专利、厂商白皮书、官方技术资料、既有第三方实验结果，判断 **2027–2029 年手机 Agentic AI** 将引发哪些负载/体验变化，以及团队如何投入 LLVM/编译、运行时、OS、CPU↔GPU↔NPU、内存/SoC、CPU 微架构，形成 FOLLOW / BUILD / 2–3 Primary Bets（若证据允许）/ 2–3 Strategic Reserves / KILL 和逐年技术路线图。**绝对不进行或要求自有实验、真机测试、PoC、仿真或基准复现。**

### 2. 七个最终必须回答的问题：累计进展
每轮必须展示下面这一张表，**本轮的新增不是累计进展的替代品**：

| ID | 最终需要回答的核心问题 | 累计已回答 / 取得的结论 | 当前状态 | 最主要剩余缺口 |
|---|---|---|---|---|
| FQ1 | 2027–29 哪 3–5 项 Agent 用户/负载变化最重要？ | 需写当前趋势排序和证据 | ADEQUATE / PARTIAL / GAP / CLOSED | 年份、用户价值、公开证据 |
| FQ2 | 学术、产业、竞争产品和专利发展到什么水平？ | 需写已建立的机制和最强软件基线 | 同左 | 手机全链路公开数据 |
| FQ3 | 哪 3–5 条独特跨层架构主线值得保留？ | 需写跨 AO 归并和边界 | 同左 | 差异化、重叠、成熟度 |
| FQ4 | 软件已能解决什么，CPU/uArch 还真正缺什么？ | 需写硬件价值是否得到公开资料支持 | 同左 | 物理成本/控制点与替代方案 |
| FQ5 | Primary Bets/Reserves/Kill 怎样定？ | 需写正式组合 vs 暂定候选，不能凑数 | 同左，可标 PROVISIONAL | 正式 SSOT 收敛与证据 |
| FQ6 | 2027、2028、2029 的分层路线图如何演进？ | 需写按年度/技术层的累计结论 | 同左 | 管理层定稿和取舍 |
| FQ7 | 哪些公开证据足以升级、保留或淘汰各方向？ | 需写论文实验、专利权利要求、厂商原始资料、反证 | 同左 | 未公开证据只标不确定性 |

**状态定义：** ADEQUATE=公开证据足以形成范围明确的战略判断；PARTIAL=主要研究已进行但核心比较/定案仍缺；GAP=缺失关键公开证据；CLOSED=在特定问题范围已有可辩护的完成或淘汰结论；PROVISIONAL=已有暂定建议但尚未正式变更投资组合。**ADEQUATE 不意味着全部论文看完，GAP 不意味着必须开展实验。**

### 3. 主要技术领域覆盖情况
每轮对下面七类作短表：领域｜累计覆盖程度/主要证据｜状态｜关键缺口。

1. Agent 负载与用户体验、个人上下文和主动 Agent（T1–T8）。
2. CPU 核心、缓存、uArch 与运行阶段特性（CG-06/CG-01/R2）。
3. LLVM/AArch64 编译、operator fusion、codegen、动态放置/融合（CG-06/C）。
4. Agent framework/runtime 与可信工具操作、回滚权限（PT-A/AO2/AO5）。
5. OS 调度与 NPU 资源控制、QoE/foreground 保护（C/AO1）。
6. CPU↔GPU↔NPU、共享内存、版本化状态与驻留生命周期（AO1/AO3/B-residual）。
7. 低功耗域、CHRE、always-on 升级控制（AO4/CG-07）。

**覆盖度不是文件计数**：重要资料需深读原方法/实验/限制或专利权利要求；数据平台可迁移性要单独标注。未直接证实的手机系统效益要明示 GAP。

### 4. 防跑偏检查
每轮给出 **对齐 / 有偏移（原因、纠正）**，至少核查：
- 手机优先、2027–29、CPU/uArch/编译/SoC 仍在研究目标中？
- 没把软件/模型研究或‘Agent’品牌宣传当成硬件差异化价值？
- 最强软件基线、竞争产品、专利与否定证据有核查？
- 有否强行凑 2–3 个 Primary Bets 或混淆暂定分数/正式判定？
- 全部判断基于公开资料；未进行或要求任何实验/PoC？

### 5. 下一步及其必要性
指明哪一个或哪几个 FQ 尚缺、接下来深读哪类权威公开来源、可能如何改变投资决策；优先最小有价值研究阶段，不做开放式资料堆积。不把后续实验当作完成研究的门槛。

### 6. 本轮增量与 SSOT
简短列新深读的重要来源、Claim/EvidenceCase 新增/反证、投资状态变化或无变化、原始资源去重、提交 SHA 和 CI 验证。质量门禁未完成时明确写未通过，不能预先宣布成功。
