# 06-opportunities

Canonical CPU/uArch Architecture Opportunity objects introduced by Data Model 2.4.

An Opportunity synthesizes grounded Claims, Product Trends and Capabilities into a bounded cross-layer architecture problem space.

It is not evidence, not a Trend, not a Direction and not a silicon commitment.

Round 15A upgrades AO-1..AO-5 from SEED_MAPPED to EVIDENCE_MAPPED.
