## 3. 正文展示词汇约束（所有 15 页）

**用户可见 PPT：禁止使用 `投资`、`投资机会`、`投资组合`、`投资优先级` 等商业化措辞。** 合适的研发用词示例：

| 原用词 | 建议替换 |
|---|---|
| 投资组合 | 技术方向组合 / 技术路线 |
| 投资建议 | 技术建议 / 路线建议 / 立项建议 |
| 投资优先级 | 技术优先级 / 推进顺序 |
| 硬件投资边界 | 新硬件立项条件 / 硬件研发边界 |
| Primary Bet | 优先工程方向（不能让研究内部标签出现在 PPT） |
| Reserve Bet | 条件研究储备 / 需要进一步验证的技术问题 |
| Kill / Do Not Invest | 当前缺少足够依据的立项方向 / 暂不推进 |

不要全局字符串机械替换为同一个词，应按句子的主语/对象区分**研究、工程实现、跨团队协作、项目立项或技术验证**。标题需要说明具体动作、实际意义，不只是用另一组抽象词掩盖问题。

研究仓历史证据/论文原始标题不因 PPT 展示规范被抹除。若论文原文自身使用 `investment` 等，可仅在后台来源记录中保留原题，正文面向领导的转述须使用技术语言。最终合并时从 PPTX XML **扫描每页可见文本**，发现禁用词先修改源 PPT，再统一导出 PNG。
