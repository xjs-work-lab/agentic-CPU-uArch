# S03 Speaker Notes｜当前技术组合与硬件证据门槛

**本页先讲结论**：当前公开证据支持三项工程/平台优先方向、三项条件研究储备，以及零项足以作为独立 Agent 专用 CPU 新硬件主押注的方向。这不是说 CPU 不重要，也不是永久否定硬件价值；它是一个严格按公开证据设定的当前决策边界。

**第一层：三项优先工程与平台能力。**（1）CPU/LLVM 异构快速路径：利用已有 AArch64/SME2 等 ISA 与 LLVM/内核优化，按具体阶段和后端能力决定 CPU/NPU/GPU 的合适分工，不宣称 CPU 总是更快，也不宣称需要新 ISA。（2）可信工具动作与结果核验：由 Agent 框架、应用和 OS 合作管理权限、重新绑定当前操作目标、核验真实外部效果，并在必要时进行有界恢复。（3）Runtime/OS 调度与前台 QoE：运行时观察动态任务 DAG，管理 CPU/GPU/NPU 阶段放置、队列/内存争用和前台体验。三项方向属于不同软件/系统责任，不是三颗新芯片。

**第二层：三项开放条件研究。** A：完整可观察账本、用户历史、权限与 OS 状态之外，是否存在能改变正确动作决策的不可重建私有进度信息？B-residual：跨 CPU/NPU/内存的派生状态版本、失效和恢复是否仍有无法被强软件版本化、缓存、OS/HAL 管理吸收的物理成本？R2：在角色池化、软亲和性和通用缓存机制之后，CPU 续执行局部性是否仍有独立且可复核的真实手机收益？这三项都是研究假设，未通过证据门槛，不能画成已批准项目。

**第三层：零项新硬件主押注。** DEC-PORTFOLIO-002 的当前状态是没有足够公开证据支持独立差异化 Agent CPU 硬件 Primary Bet。DEC-A-008 已将 A 从历史 Primary Bet 正式降为 CONDITIONAL_RESERVE；旧 82.5 仅作历史记录，不得当成当前分数或重新立项理由。这是公开资料研究的决策，不是对 A 的实验性否证。

**什么证据会让我们重开硬件讨论？** 需要外部公开原始证据、强软件/通用硬件对照、可复核的不可吸收物理残差，并证明它在真实手机/系统层面具有独立意义。仅有软件功能价值、普通缓存/版本化、NPU 队列管理或产品“Agentic”宣传，都不足以推出新硬件。

**证据与范围**：以 current.md、DEC-PORTFOLIO-002、DEC-A-008 为决策权威，并由公开手机 CPU/NPU、HeRo、LAS、ProgRouter、Android NPU Manager、Apple/Google 平台材料等提供工程背景。项目未进行自有实验、PoC 或模拟；历史研究编号仅放备注/仓库，不放投影页面。
