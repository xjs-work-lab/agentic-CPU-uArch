## 3. 源级验收方法与限制

GitHub 已重新读取四张最终 v01 SVG 并核查：
- XML 风格的元素开闭标签栈平衡；
- 无重复属性名、无未转义的 XML `&`；
- 尺寸 `width=1600 height=900 viewBox=0 0 1600 900`；
- 必要中文主张、设备数字及重点连线 `path d` 出现；
- 内容与 [03-evidence-map](../03-evidence-map.md) 和 [04-risk-boundaries](../04-risk-boundaries.md) 对齐。

**不能从这些自动检查宣称**：中文文本已经完全不越界；箭头端点在 PNG 上光学对齐；行距和字体良好；四页放一起一定统一；PPTX 对象已可编辑。SVG 矢量文本、框、箭头能被图形编辑器修改，**并不等于被 SlidePoise 原生重建为 PowerPoint 元素**。

### G2-B｜技术反证问答（建议独立 reviewer）
不看设计意图，要求观察者回答：
1. S03 里「0 项」是否意味着停止 CPU 优化？正确应是否。
2. S05 NPU 是否固定负责整个 DAG？正确应否；部署需阶段/资源条件。

4. S15 2029 是否保证芯片流片？正确应否；只是条件研究方向。
