## 2. 投影内容

### 一级｜优先建设：三项工程与平台能力
1. **CPU / LLVM 异构快速执行**：复用现有 AArch64 / SME2 等能力，优化微内核、布局与分阶段放置；按真实阶段保留合适 CPU 角色，不假设 CPU 总胜 NPU。
2. **可信工具动作与结果核验**：明确权限并重新确认操作目标，核验外部效果，支持有界恢复；关注动作是否正确完成，而不只是模型或工具调用成功。
3. **Runtime / OS 异构调度与前台体验**：动态 DAG 与后端能力感知放置，兼顾共享内存争用与前台 QoE；这是运行时与系统协同，不推出新增 CPU 硬件需求。

### 二级｜条件研究：三项开放假设
1. **额外任务进度信息**：完整可观察账本之外，是否仍有不可重建的私有进度信号？门槛是外部公开证据证明它会改变正确执行决策。
2. **跨引擎派生状态有效性**：CPU / NPU / 内存间是否存在软件无法吸收的状态失效成本？先对照版本化、缓存复用与 OS / HAL 管理。
3. **CPU 续执行局部性**：强软件调度、亲和性与通用缓存后，是否仍有独立收益？必须有可复核的真实手机证据。

条件研究用浅色虚线框和“条件开放”表示；禁止用已批准项目的实心勾选或确定交付日期表达。

### 三级｜当前证据结论
**0 项新硬件主押注**。画面要说明这是“当前没有任何 Agent 专用 CPU 新硬件方向获得充分公开证据支持，可作为独立主押注”，不是“CPU 没有价值”或“未来永远不研究硬件”。

### 重新评估门槛
外部公开原始证据 + 强软件 / 通用硬件对照 + 不可被现有基线吸收的物理残差 + 可复核的引擎 / 手机层影响，才重新评估新硬件；不是预先承诺立项。
