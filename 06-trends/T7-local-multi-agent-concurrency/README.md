# T7 — Local multi-Agent concurrency & shared model/state

## Product thesis
T7 asks whether multiple local Agents sharing models, KV, adapters, memory and device resources create a distinct smartphone control point beyond C scheduling/orchestration and T5 state lifecycle. Round 14-A is actively pressure-testing this boundary.

## Interpretation invariant
A paper or product may strengthen this Trend while simultaneously narrowing the novelty of one or more linked Directions.

> **Prior art constrains novelty, not product relevance.**

## Round 14-A / MobiMem pressure
PAPER-103 confirms a multi-role mobile Agent architecture but does not isolate multi-Agent identity as a new physical/system control point. Its measured gains are attributable to software-visible DAG scheduling, reusable state and replay validity. T7 therefore remains FRONTIER_SIGNAL / WATCH pending LOCAL and EcoAgent FULL_10Q.


## Round 14-A / LOCAL pressure
PAPER-104 is the strongest shared-model T7 seed so far. It reports useful cross-Agent pre-prefill, but explicitly treats Agent identity as provenance rather than an unconditional KV-validity key. The hard state is token/context/adapter/version plus future-consumer demand and resource pressure. This further narrows standalone T7 differentiation toward C + T5 ownership. EcoAgent remains the final scheduled deep read before the T7 ownership decision.


## Round 14-A / EcoAgent + final ownership
PAPER-105 is independent AAAI 2026 mobile-system evidence, but its multi-Agent gain comes from role specialization, local verification and communication compression; its “device-side” models execute on RTX 3090 simulation, not phone silicon.
