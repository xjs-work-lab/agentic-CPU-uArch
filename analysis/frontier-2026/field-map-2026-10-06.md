## Decision-grade blind spots after current 10Qs

1. **Agent pipeline structure as an optimization object**
   - Agent-X shows Agent-specific structure can already be exploited in software.
   - Consequence: A/C must beat Agent-aware software optimization, not generic LLM baselines only.

2. **Time utility / execution-coupled computation**
   - TimelyLLM proves useful-by timing is actionable.
   - Consequence: broad time-utility scheduling is too crowded for a new Bet; search only for residuals beyond strong serving-runtime control.

3. **Foreground protection under persistent/background AI**
   - Sereno directly validates severe asymmetric mobile interference and large generic recovery.
   - Consequence: Foreground-Protected Persistent Agent becomes a mandatory evaluation scenario, while generic QoS/bandwidth protection becomes part of G1/B4.

4. **Long-horizon semantic execution state**
   - AgentProg establishes strong application/runtime semantic-state value.
   - Consequence: A's B4-TX baseline must include reconstructible program/control/data-flow/belief state; semantic-state value alone is not lower-layer proof.

5. **Fine-grained heterogeneous stage/operator placement**
   - ShadowNPU establishes a strong optimized-NPU frontier using numerical-role decomposition, graph bucketing and CPU/NPU pipelining.
   - Consequence: CG-06 must survive NPU-OPT/HETERO-OPT; naive NPU offload is no longer a sufficient comparator.
