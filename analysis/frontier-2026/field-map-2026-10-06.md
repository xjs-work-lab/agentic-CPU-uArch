## First-round blind spots revealed

1. **Agent pipeline structure as an optimization object**
   - Agent-X shows the full on-device Agent pipeline has different bottlenecks from ordinary chat-style LLM inference.
   - Implication: workload model must include planner/arbiter/tool/GUI/context phases, not only token throughput.

2. **Time utility / execution-coupled computation**
   - TimelyLLM shows compute can be aligned with when Agent outputs become useful.
   - Implication: A/R1/C need a stronger execution-aware baseline; potential new control variable is *useful-by time*, not simple ready/runnable state.

3. **Foreground protection under persistent/background AI**
   - Sereno directly validates severe asymmetric foreground-vs-background interference on commercial smartphones.
   - Implication: the Foreground-Protected Persistent Agent anchor should become a top-level evaluation scenario.

4. **Semantic execution state remains software-rich**
   - AgentProg shows program-like variables/control-flow/belief-state can materially improve long-horizon mobile Agent execution.
   - Implication: semantic information is valuable, but software/runtime may capture much of it; this raises the bar for A/R3 hardware claims.

5. **Fine-grained heterogeneous partitioning remains active**
   - ShadowNPU demonstrates NPU + CPU/GPU partition/pipeline value due to precision/operator differences.
   - Implication: CG-06 framing is strengthened; simple engine-level placement is likely too coarse.

## Second-Bet hypotheses to test next

Do **not** create a new Bet yet. Pressure-test three candidate formulations:

1. **Execution-Time Utility Control**
   - Agent compute scheduled by useful-by / latest-useful-time semantics across generation, tool execution and device state.
   - Must prove it is not merely R1/TimelyLLM-style scheduling or A renamed.

2. **Foreground-Protected Persistent Agent Control Plane**
   - Cross-engine QoS control that protects foreground interaction while persistent Agent work continues.
   - Must prove a reusable Agent-specific residual beyond generic bandwidth/QoS control and Sereno-like software yielding.

3. **Agent-Aware Heterogeneous Stage Graph Placement**
   - Placement across CPU/NPU/GPU based on stage/operator precision, state reuse, dispatch cost and Agent criticality.
   - Must prove differentiated Agent value beyond CG-06 generic heterogeneous placement.
